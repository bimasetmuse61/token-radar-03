    How radar-4 prices a protocol with no token

    implied = TVL × multiple × growth × maturity × breadth, computed for a low, a base and a high from the same formula. No protocol’s name is ever special-cased: every figure below is recomputed from the snapshot on every run.

    • Peer hygiene: a trading peer must record a token and be launch-comparable — not a CEX-category protocol, not a name beginning with an exchange’s, and no whole word wrapped, staked or staking. An exchange token’s market cap and a wrapped asset’s mirror price are not evidence for a fresh launch, so they never price a row.
    • Outlier trim: inside any peer set of 8 or more, multiples outside the set’s own P10–P90 are set aside before quartiles are taken. This snapshot’s raw global set reaches a 400× multiple; one such peer must not price forty protocols.
    • Scale-matched weighting: a peer’s weight for a row is 1 / (1 + |log₁₀(peer TVL / row TVL)|) — full weight at the row’s own scale, a tenth two decades away. Category P25, median and P75 are weighted quantiles, so a $60M protocol is priced by $10M–$600M launches, not by a $40B one.
    • Shrinkage by effective peers: the effective count nEff = (Σw)² / Σw² replaces the raw count in used = (nEff × category + 4 × global) / (nEff + 4), applied to each quartile and clamped to 0.03–1.50. A category with no peers is priced on the global weighted quartiles.
    • Growth, concave: 1 + 0.55 × sign(g) × √(|g| / 100) with g = clamp(7d change, −60%, +200%). A one-week +4,448% spike (this snapshot has one) is weak evidence and must not mint rank; a steady +25% week counts for real. An unreported change counts as neutral — and widens the band instead.
    • Maturity, log-age: 0.70 + 0.30 × ln(1 + age / 365) / ln 5, capped at four years: the first tokenless year is the strongest survival evidence, the fourth adds little. An unknown listing date counts as 365 days — and widens the band.
    • Breadth: 1 + min(chains − 1, 9) × 0.01.
    • Uncertainty is shown, not hidden: each missing field (7d change, listing date) widens the row’s band by 20% on both sides; the base value never moves. The evidence grade sums the row’s effective peers (≥8 strong, ≥3 fair) and its data completeness: A strong, B fair, C thin.
    • Farm plans: fourteen plan archetypes — swap volume for DEXes, supply-and-borrow for lending, stake cycles for liquid staking, bridge round trips for bridges, network use for tokenless chains, and so on. Gas is priced per chain from a cost table (Ethereum $12 an action, Solana $0.05, Base $0.15, default $1), capital is sized by TVL tier, the holding period is a quarter of the protocol’s tracked age held between 30 and 120 days, and one step in every plan is tailored to the row itself — a falling TVL, a one-week spike, an unknown listing date, a young record or a wide chain spread changes what to do first. Each plan’s budget (total gas, active minutes, capital, hold) is summed from its own steps and printed above it.
